# EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE: 02/11/2026
## Name: Sanjarika V
## Reference no.: 26016005
## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1.  Open Autodesk Fusion 360 and create a new design. Select the Front view (XY Plane) and click on Create Sketch.   <img width="418" height="218" alt="image" src="https://github.com/user-attachments/assets/81d2cb9e-0771-4b49-b0f2-2d1f41c3bfbd" />

2. Draw a vertical line and a horizontal line through the centre point. Using the Centre Point Arc tool, draw an arc of R110 with its centre at the origin. Close it with a horizontal line of 220 mm at the bottom.
3. In the same sketch, draw a rectangle of 120 mm width and 60 mm height at the centre. Its bottom edge must be on the horizontal line. Give the dimensions using the Sketch Dimension tool. Click on Finish Sketch.
4. Select the Extrude tool. Select the arc profile (the outer part, not the rectangle), set the distance to 150 mm and the direction to Symmetric. Click OK.
5. Select the Extrude tool again and use the Cut option. Select the middle rectangle (120 x 60 mm) and cut it through the full 150 mm. The hollow inside of the clamp is now ready.<img width="387" height="462" alt="Screenshot 2026-11-11 215110" src="https://github.com/user-attachments/assets/936dba5b-5ce9-4921-94ec-ca68f60a1feb" />

6. Select the Top view (XZ Plane) and click on Create Sketch. Draw a horizontal centre line.
7. On the left and right sides of the centre, mark two points 150 mm from the centre. At each point, draw a circle of Ø40 mm and a bigger circle of R60.
8. Use the Line tool to join the two R60 circles on the top and bottom, to make a slot shape. Use the Trim tool to remove the extra parts. Click on Finish Sketch.
9. Select the Extrude tool. Select the slot profile (not the Ø40 mm holes), set the distance to 30 mm and the operation to Join. The base tabs are now ready. <img width="318" height="322" alt="Screenshot 2026-10-20 133440" src="https://github.com/user-attachments/assets/8a8d77d7-d3af-408b-bdeb-9f00db4ef5af" />

10. Select the top of the arch, or the Top view (XZ Plane), and click on Create Sketch. Draw a circle of Ø20 mm at the centre using the Center Diameter Circle tool. Click on Finish Sketch.
11. Select the Extrude tool with the Cut option and cut the Ø20 mm circle through the top of the arch.
12. Check all the dimensions: 300 mm centre distance, 420 mm overall length, Ø40 mm and Ø20 mm holes, R60, R110, 120 x 60 mm opening, 30 mm base thickness, 150 mm width and 110 mm height. Save the model with the required file name.
13. Switch to the Drawing workspace and create the drawing in ISO standard format. Add the Front view, Top view and Right side view along with the Isometric view. Apply the dimensions, verify the views and save the drawing.
